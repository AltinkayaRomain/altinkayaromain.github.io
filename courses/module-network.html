2. Routage Statique & Dynamique

Janvier 2025 35h — 5 jours Bloc A1/C4 · A2/C7
✅
Avantages
Simple à configurer, pas de surcharge CPU, prédictible, sécurisé (pas d'échange de routes).
❌
Inconvénients
Pas scalable, maintenance manuelle, aucune adaptation aux pannes.
Route statique Cisco
! Route vers 192.168.2.0/24 via le prochain saut Router(config)# ip route 192.168.2.0 255.255.255.0 192.168.1.1 ! Route par défaut (Gateway of Last Resort) Router(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.1

OSPF (Open Shortest Path First) = protocole à état de lien. Chaque routeur connait la carte complète du réseau.

🗺️
Link-State
Chaque routeur construit une LSDB (Link-State Database) = carte complète du réseau.
⚡
Coût (Métrique)
Coût = 100 Mbps / Bande passante. OSPF préfère le chemin le plus RAPIDE, pas le plus court.
🏛️
Area 0 (Backbone)
Obligatoire. Toutes les autres aires doivent y être connectées directement ou via ABR.
📡
DR / BDR
Sur réseau multi-accès, élection d'un Designated Router pour réduire les échanges LSDB.
Config OSPF Cisco
Router(config)# router ospf 1 Router(config-router)# router-id 1.1.1.1 ! Wildcard mask = inverse du masque (ex: /24 → 0.0.0.255) Router(config-router)# network 192.168.10.0 0.0.0.255 area 0 Router(config-router)# passive-interface g0/1 ! Ne pas envoyer OSPF sur ce port
Rappel Wildcard : /24 → 0.0.0.255 · /25 → 0.0.0.127 · /30 → 0.0.0.3
ProtocoleTypeMétriqueConvergenceUsage
RIP v2Vecteur de distanceSauts (max 15)Lente (30s)Petits réseaux / labo
EIGRPHybride (Cisco)Composite (BW+Delay)RapideRéseaux Cisco purs

Router-on-a-Stick = routage inter-VLAN avec une seule interface physique découpée en sous-interfaces logiques.

RoaS — Config Cisco
Router(config)# interface g0/0 Router(config-if)# no shutdown Router(config)# interface g0/0.10 Router(config-subif)# encapsulation dot1Q 10 Router(config-subif)# ip address 192.168.10.254 255.255.255.0 Router(config)# interface g0/0.20 Router(config-subif)# encapsulation dot1Q 20 Router(config-subif)# ip address 192.168.20.254 255.255.255.0
Du côté switch : Le port relié au routeur doit être configuré en mode trunk, pas access.

3. Switching, VLAN & STP

Janvier 2025 35h — 5 jours Bloc A1/C4 · A2/C7
🧱
VLAN (Access)
Port dédié à un seul VLAN. La trame sort SANS tag (transparence pour le PC).
🚂
Trunk 802.1Q
Transporte plusieurs VLANs sur un seul câble. Ajoute un tag 4 octets dans la trame Ethernet.
🏷️
Native VLAN
Seul VLAN passant sans tag sur un trunk. Changer le défaut (VLAN 1) pour éviter le VLAN Hopping.
📢
VTP (optionnel)
Propage la configuration VLAN entre switchs. Dangereux en production si mal configuré.
Config VLAN Cisco Switch
! Créer un VLAN Switch(config)# vlan 10 Switch(config-vlan)# name COMPTA ! Port Access Switch(config)# interface f0/1 Switch(config-if)# switchport mode access Switch(config-if)# switchport access vlan 10 ! Port Trunk Switch(config)# interface g0/1 Switch(config-if)# switchport mode trunk Switch(config-if)# switchport trunk native vlan 99 Switch(config-if)# switchport trunk allowed vlan 10,20,30

STP empêche les boucles de commutation qui causeraient des Tempêtes de Broadcast (réseau mort en secondes).

👑
Root Bridge
Switch avec la plus petite priorité (défaut 32768) ou la plus petite MAC. C'est lui le "chef".
📧
BPDU
Bridge Protocol Data Units. Messages échangés entre switchs pour surveiller la topologie.
🚫
Port Bloqué
STP désactive logiquement un port pour casser la boucle. Réactivé si le lien actif tombe.
⚡
RSTP (802.1w)
Version rapide du STP. Convergence en quelques secondes vs 30-50s pour le STP classique.
PortFast + BPDU Guard : Sur les ports qui connectent des PC (jamais d'autres switchs), activez PortFast pour accélérer la connexion, et BPDU Guard pour couper le port si un switch inconnu est branché.

Le switch apprend les adresses MAC dynamiquement dans sa table CAM (Content Addressable Memory).

📚
Apprentissage
Quand une trame arrive, le switch enregistre l'adresse MAC source + le port d'arrivée.
🎯
Forwarding
Si la MAC destination est dans la table → envoi direct sur le bon port. Sinon : Flooding.
🌊
Flooding
MAC inconnue ou broadcast → la trame est envoyée sur TOUS les ports sauf le port source.
Voir la table CAM
Switch# show mac address-table Switch# show mac address-table dynamic Switch# clear mac address-table dynamic
Commandes Switch — Diagnostic
# État des VLANs Switch# show vlan brief # État des interfaces Switch# show interfaces trunk Switch# show interfaces status # STP Switch# show spanning-tree Switch# show spanning-tree vlan 10 # Sécurité ports Switch(config-if)# switchport port-security maximum 2 Switch(config-if)# switchport port-security violation shutdown

4. Transport : TCP vs UDP

Novembre 2024 Inclus TCP/IP — 21h Bloc A1/C4

Three-Way Handshake TCP

1️⃣
SYN
Client → Serveur : "Bonjour, je veux me connecter, mon numéro de séquence est X."
2️⃣
SYN-ACK
Serveur → Client : "Reçu (ACK=X+1), je suis prêt, mon séquence est Y."
3️⃣
ACK
Client → Serveur : "Parfait (ACK=Y+1), connexion établie. J'envoie les données."
CritèreTCPUDP
ConnexionOrienté connexionSans connexion
FiabilitéAccusés de réceptionBest-effort
OrdreRéordonne les paquetsPas d'ordre garanti
DébitPlus lent (overhead)Très rapide
UsagesWeb, Mail, FTP, SSHDNS, DHCP, VoIP, Streaming, Jeux

5. Téléphonie IP (ToIP) & WiFi

Octobre 2025 21h — 3 jours Bloc A1/C4 · A2/C7
📞
SIP
Session Initiation Protocol. Gère la signalisation (établir/terminer l'appel). Port 5060 (UDP/TCP).
🎤
RTP
Real-time Transport Protocol. Transporte la voix en temps réel. Ports dynamiques (UDP).
🏢
IPBX
Serveur qui gère les appels internes + les connexions vers le réseau téléphonique public (RNIS/SIP Trunk).
🏷️
VLAN Voix
Isoler la voix dans un VLAN dédié + activer QoS pour prioriser les paquets voix. DSCP EF.
Asterisk — sip.conf (extrait)
[general] context=default allowguest=no [1001] type=friend secret=motdepasse host=dynamic context=interne callerid=Alice <1001>

[interne] ; Appel entre postes internes exten => 1001,1,Dial(SIP/1001,30) exten => 1001,2,Voicemail(1001@default) exten => 1002,1,Dial(SIP/1002,30)

6. Architecture nTiers (LAMP)

Octobre 2025 14h — 2 jours Bloc A1/C3 · C4
🖥️
1-Tier (Monolithique)
Tout sur une seule machine. Simple mais pas scalable, pas de redondance.
🔀
2-Tier (Client/Serveur)
Client ↔ Serveur DB. Le client fait une partie du traitement (application épaisse).
🏗️
3-Tier (LAMP)
Présentation (Apache) ↔ Logique (PHP) ↔ Données (MySQL). Séparation claire des responsabilités.
☁️
nTiers / Microservices
Chaque composant est indépendant, scalable et déployable séparément. Base du cloud moderne.
Déploiement LAMP — Debian/Ubuntu
# Installation apt install apache2 php php-mysql mariadb-server -y # Sécuriser MySQL mysql_secure_installation # Tester PHP echo "<?php phpinfo(); ?>" > /var/www/html/info.php # Activer mod_rewrite (pour les CMS) a2enmod rewrite systemctl restart apache2

7. Sécurité : VPN & Firewalling

Octobre 2025 35h — 5 jours Bloc A1/C4 · A2/C7
📋
ACL Standard (1-99)
Filtre uniquement sur l'IP source. À placer le plus près de la destination.
🎯
ACL Étendue (100-199)
Filtre Source + Destination + Protocole + Port. À placer le plus près de la source.
ACL Étendue — Exemple
! Autoriser HTTP depuis 192.168.1.0/24 vers n'importe où Router(config)# ip access-list extended WEB_OUT Router(config-ext-nacl)# permit tcp 192.168.1.0 0.0.0.255 any eq 80 Router(config-ext-nacl)# permit tcp 192.168.1.0 0.0.0.255 any eq 443 Router(config-ext-nacl)# deny ip any any log ! Appliquer sur l'interface (IN = entrant depuis le LAN) Router(config-if)# ip access-group WEB_OUT in
Implicit Deny : Toute ACL se termine par un "deny all" invisible. Si vous n'autorisez pas explicitement, c'est bloqué.
TypeRatioUsage
NAT Statique1:1Exposer un serveur (DMZ). IP publique fixe → IP privée fixe.
NAT DynamiqueN:NPool d'IPs publiques partagé entre plusieurs hôtes.
PAT (NAT Overload)N:1Toute une LAN partage une seule IP publique (Box internet). Utilise les ports TCP/UDP pour différencier.
PAT Cisco — Accès Internet
! Définir les interfaces Router(config-if)# ip nat inside ! Interface LAN Router(config-if)# ip nat outside ! Interface WAN ! ACL pour le trafic à nater Router(config)# access-list 1 permit 192.168.1.0 0.0.0.255 ! PAT sur l'interface WAN Router(config)# ip nat inside source list 1 interface g0/0 overload
🔒
VPN Site-à-Site
Tunnel chiffré entre deux routeurs/firewalls. Connecte deux sites distants comme s'ils étaient sur le même LAN. (IPsec)
💻
VPN Client (SSL/TLS)
Un utilisateur distant se connecte au réseau d'entreprise via son PC. (OpenVPN, Cisco AnyConnect)
🛡️
IPsec — IKE Phase 1
Authentification des routeurs + échange de clés Diffie-Hellman. Crée le tunnel ISAKMP.
📦
IPsec — IKE Phase 2
Négociation des paramètres de chiffrement des données (AES, SHA). Crée les SA (Security Associations).
🏰
DMZ
Zone tampon entre Internet et le LAN interne. Les serveurs publics (Web, Mail) y sont placés.
🔍
Stateful vs Stateless
Stateful garde la trace des connexions établies (meilleur). Stateless évalue chaque paquet isolément (ACL).
🌐
Solutions Courantes
pfSense/OPNsense (open source), Cisco ASA, Fortinet FortiGate, Palo Alto.
Règle d'or Firewall : Tout bloquer par défaut (default deny), puis autoriser uniquement ce qui est nécessaire. Jamais l'inverse.

8. Méthodes de Dépannage IP

Mars 2026 35h — 5 jours Bloc A1/C4 · A2/C5 · C7

Démarche Méthodique (Bottom-Up)

🔌
L1 — Physique
Câble branché ? LED allumée ? show interfaces → chercher "down/down".
🔗
L2 — Liaison
Bon VLAN ? Port en mode access/trunk correct ? ARP qui répond ? show mac address-table
🗺️
L3 — Réseau
IP correcte ? Masque OK ? Gateway joignable ? Route existante ? ping + traceroute
🚪
L4+ — Transport / App
Port ouvert ? Firewall bloquant ? Service actif ? telnet IP PORT pour tester un port.
Boîte à outils Tshoot
# --- Windows --- ipconfig /all # IP, MAC, Gateway, DNS ping 8.8.8.8 # Test connectivité tracert 8.8.8.8 # Chemin emprunté nslookup google.com # Test DNS netstat -an # Connexions actives + ports en écoute arp -a # Cache ARP local # --- Linux --- ip a # Interfaces et IPs ip route show # Table de routage ss -tulnp # Ports en écoute (remplace netstat) dig google.com # Test DNS complet tcpdump -i eth0 -n # Capture trafic temps réel curl -I http://serveur # Test applicatif HTTP
Documentation : Toujours rédiger un rapport d'intervention : symptôme → diagnostic → actions → vérification → résolution. C'est exigé à l'examen.

9. Monitoring & Supervision

Mai 2026 21h — 3 jours Bloc A1/C3 · C4 · A2/C7
📊
Nagios / Centreon
Supervision par checks actifs (ping, services). Alertes par mail/SMS. Le standard historique.
📈
Zabbix
Supervision avancée avec agents, SNMP, auto-découverte, dashboards et alertes configurables.
🔭
Prometheus + Grafana
Stack moderne. Prometheus collecte les métriques (pull), Grafana les affiche. Populaire en DevOps.
📡
SNMP
Protocole de supervision réseau. v3 recommandé (chiffré). Permet d'interroger routeurs, switchs, serveurs.
OID & MIB : SNMP utilise des OID (Object IDentifier) pour identifier chaque métrique. Les MIB sont les "dictionnaires" qui les définissent.
SNMP — Commandes de base
# Interroger un équipement (community string "public") snmpwalk -v2c -c public 192.168.1.1 # Récupérer une valeur spécifique (uptime) snmpget -v2c -c public 192.168.1.1 1.3.6.1.2.1.1.3.0 # Activer SNMP sur Cisco (v2c) Router(config)# snmp-server community public RO Router(config)# snmp-server host 192.168.1.100 version 2c public
