#01 DÉCOUPAGE · NOMBRE MAGIQUE
Facile

Vous disposez du réseau 192.168.1.0/24.
Vous voulez le découper en 4 sous-réseaux égaux.
Quel masque utiliser ? Quel est le nombre magique ? Listez les 4 adresses réseau.

💡 4 sous-réseaux = 2² → on emprunte 2 bits → /24 + 2 = /26. Masque 255.255.255.192. NM = 256 − 192 = 64.
Correction complète :
4 sous-réseaux → 2n ≥ 4 → n=2 → /26 (masque .192) · NM = 64
Réseau 1 : 192.168.1.0 → hôtes .1→.62 → BC .63
Réseau 2 : 192.168.1.64 → hôtes .65→.126 → BC .127
Réseau 3 : 192.168.1.128 → hôtes .129→.190 → BC .191
Réseau 4 : 192.168.1.192 → hôtes .193→.254 → BC .255
#02 IDENTIFICATION
Facile

À quel sous-réseau appartient l'IP 192.168.10.45/27 ?
Donnez l'adresse réseau, la première IP hôte, la dernière IP hôte et le broadcast.

💡 /27 → masque .224 → NM = 32. Division : 45 ÷ 32 = 1 (entier) → 1×32 = 32. C'est l'adresse réseau.
Correction :
NM = 256 − 224 = 32
45 ÷ 32 = 1 (entier) → 1 × 32 = 32 → réseau = 192.168.10.32/27
1ère hôte : 192.168.10.33 · Dernière hôte : 192.168.10.62
Broadcast : 32 + 32 − 1 = 192.168.10.63
#03 SOUS-RÉSEAU POUR X HÔTES
Facile

Vous devez créer un sous-réseau dans 10.0.0.0/24 pour accueillir au moins 14 hôtes.
Quel est le masque minimal ? Combien d'hôtes utiles ce masque offre-t-il ?

💡 2h − 2 ≥ 14 → 2³−2=6 (non) → 2⁴−2=14 ✅ → 4 bits hôtes → /28. Masque .240 → NM = 16.
Correction :
On cherche h tel que 2h−2 ≥ 14
h=3 → 2³−2=6 ❌ · h=4 → 2⁴−2=14 ✅
Masque : /32−4 = /28 (255.255.255.240) · NM = 256−240 = 16
Hôtes utiles : 14 exactement (juste ce qu'il faut !)

#05 IDENTIFICATION · /26
Moyen

L'IP 10.0.0.200/26 appartient à quel sous-réseau ?
Cette IP est-elle la dernière IP hôte de son sous-réseau ? (oui/non)

💡 /26 → masque .192 → NM=64. 200÷64=3 → 3×64=192. BC = 192+64−1 = 255. Dernière hôte = BC−1 = 254.
Correction :
NM = 256−192 = 64 · 200÷64 = 3 (entier) → réseau = 10.0.0.192/26
Broadcast = 192+64−1 = 10.0.0.255 · Dernière hôte = 10.0.0.254
.200 ≠ .254 → non, ce n'est pas la dernière IP hôte.

#07 IDENTIFICATION · CLASSE B
Moyen

L'IP 172.20.45.130/25 : trouvez son réseau, son broadcast, et déterminez si elle est dans la première ou seconde moitié du /24 parent.

💡 /25 → masque .128 → NM=128. 130÷128=1 → 1×128=128. La 1ère moitié = .0→.127, la 2ème = .128→.255.

#08 DÉCOUPAGE · CLASSE B
Difficile

Découpez 172.16.0.0/16 en sous-réseaux de /20.
Combien obtenez-vous de sous-réseaux ? Quel est le NM (sur le 3ème octet) ?
Donnez les adresses réseau des sous-réseaux #1, #2 et #16.

💡 /20 sur une base /16 = 4 bits empruntés → 2⁴=16 SR. Le NM s'applique au 3ème octet : masque 255 sur 3ème octet = 255.255.240.0 → NM = 256−240 = 16. SR#16 = 0+(15×16) = 240.
Correction :
/20 − /16 = 4 bits empruntés → 2⁴ = 16 sous-réseaux
Masque /20 = 255.255.240.0 → NM (3ème octet) = 256−240 = 16
SR#1 : 172.16.0.0 · SR#2 : 172.16.16.0 · SR#3 : 172.16.32.0 … SR#16 : 172.16.240.0
Hôtes : 2¹²−2 = 4094 par sous-réseau
#09 VLSM · MULTI-BESOINS
Difficile

Vous avez 192.168.100.0/24. Vous devez créer 3 sous-réseaux :
• Réseau A : 60 hôtes min
• Réseau B : 25 hôtes min
• Réseau C : 10 hôtes min (lien point-à-point étendu)
En VLSM (taille décroissante), donnez le masque et l'adresse réseau de chacun.

💡 VLSM = toujours allouer du plus grand au plus petit. A→/26 (62h) start .0, fin .63. B→/27 (30h) start .64, fin .95. C→/28 (14h) start .96.
Correction VLSM :
A : 60h → 2⁶−2=62 → /26 · adresse : 192.168.100.0 · plage : .1→.62 · BC : .63
B : 25h → 2⁵−2=30 → /27 · adresse : 192.168.100.64 · plage : .65→.94 · BC : .95
C : 10h → 2⁴−2=14 → /28 · adresse : 192.168.100.96 · plage : .97→.110 · BC : .111
Espace restant : 192.168.100.112 → .255 (non alloué)
#10 IDENTIFICATION · /29
Difficile

Trouvez le sous-réseau de 10.10.10.253/29.
Cette adresse est-elle une adresse hôte valide ou le broadcast ? Justifiez avec le calcul.

💡 /29 → masque .248 → NM=8. 253÷8=31 → 31×8=248 → réseau .248. BC = 248+8−1 = 255. .253 ≠ .255 donc c'est un hôte valide.
Correction :
NM = 256−248 = 8 · 253÷8 = 31 (entier) → réseau = 10.10.10.248/29
Broadcast = 248+8−1 = 10.10.10.255
Plage hôtes : .249 → .254 · .253 est dans la plage → hôte valide ✅
#11 ROUTE FLOTTANTE
Moyen

Un routeur a deux chemins vers 0.0.0.0/0 :
• Fibre via 203.0.113.1 (lien principal)
• 4G via 198.51.100.1 (lien de secours)
Quelle distance administrative donner à la route 4G pour qu'elle soit flottante ?
Écrivez la commande Cisco complète.

💡 La route statique par défaut a AD=1. Pour qu'elle soit "flottante" (invisible tant que l'autre existe), donnez-lui une AD > 1, ex: 5. Syntaxe : ip route réseau masque nexthop AD.
Correction :
Route principale : ip route 0.0.0.0 0.0.0.0 203.0.113.1 (AD=1)
Route flottante : ip route 0.0.0.0 0.0.0.0 198.51.100.1 5 (AD=5)
Tant que la fibre est UP, seule la route AD=1 est dans la table. Si elle tombe → la route AD=5 prend le relais automatiquement.
#12 ROUTE RÉCAPITULATIVE
Difficile

Résumez ces 4 réseaux en une seule route récapitulative :
192.168.8.0/24 · 192.168.9.0/24 · 192.168.10.0/24 · 192.168.11.0/24
Trouvez le masque récapitulatif et écrivez la route Cisco (next-hop : 10.0.0.2).

💡 3ème octet en binaire : 8=0000 1000, 9=0000 1001, 10=0000 1010, 11=0000 1011. Bits communs : les 6 premiers → /16+6=/22. Masque = 255.255.252.0.
Correction :
8 = 0000 1000 · 9 = 0000 1001
10 = 0000 1010 · 11 = 0000 1011
6 bits communs → /16+6 = /22 · masque = 255.255.252.0
Réseau récapitulatif : 192.168.8.0/22
Commande : ip route 192.168.8.0 255.255.252.0 10.0.0.2
#13 IDENTIFICATION · /30 (LIEN P2P)
Facile

Un lien point-à-point entre deux routeurs utilise 10.0.0.5/30.
Quelle est l'adresse réseau ? Quelle est la seule autre IP hôte possible sur ce lien ?

💡 /30 → masque .252 → NM=4. 5÷4=1 → réseau=.4. BC=.7. Hôtes valides : .5 et .6 seulement. L'autre routeur prend .6.
Correction :
NM = 256−252 = 4 · 5÷4=1 → réseau = 10.0.0.4/30
Broadcast = 4+4−1 = 10.0.0.7
Hôtes valides : .5 (ce routeur) et 10.0.0.6 (l'autre) — seulement 2 hôtes sur un /30 !

#15 ROUTES · DISTANCES ADMINISTRATIVES
Difficile

Un routeur a ces routes vers 10.10.0.0/16 dans sa table :
• OSPF via 192.168.1.1 · • Statique via 192.168.1.2 · • RIP via 192.168.1.3
Laquelle sera choisie ? Classez-les par distance administrative (meilleure en premier).

💡 AD : Connecté=0, Statique=1, EIGRP=90, OSPF=110, RIP=120. Plus l'AD est BASSE, plus la route est PRIORITAIRE.
Correction :
Statique AD=1 · OSPF AD=110 · RIP AD=120
Route choisie → Statique (AD la plus basse)
Classement : Statique > OSPF > RIP
Note : si la route statique était configurée avec AD=200, OSPF l'emporterait.
